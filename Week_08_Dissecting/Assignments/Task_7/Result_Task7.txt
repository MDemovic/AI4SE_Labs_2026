The CLI's JSON event recorded a completed MCP tool call to coursework.word_count with that text as its argument; the tool returned "5", and Codex reported 5 words.

The first noninteractive attempt could not run the tool because it required approval. For the successful retry, I used a command-line approval override limited to the coursework server for that session. The saved configuration was not changed to auto-approve tool calls.
