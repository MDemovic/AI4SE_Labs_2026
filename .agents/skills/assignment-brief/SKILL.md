# Assignment brief

Read the specified assignment's instructions and any files they explicitly require. If no assignment is identified, use the active task only when the context makes it clear; otherwise ask which one.

Explain the goal, required steps, and exact submission items in plain language. Distinguish optional alternatives from requirements and mention any stated constraints or grading criteria. Suggest a short plan when useful, and cite the assignment file so the student can check it.

Do not complete the assignment or create its deliverables unless the user also requests that work.
